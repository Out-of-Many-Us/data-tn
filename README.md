# data-tn

Parsed Tennessee county election results, derived from the documents archived in [sources-tn](https://github.com/Out-of-Many-Us/sources-tn).

Each figure is intended to trace back to a source document by SHA-256, so that anyone can fetch the original and check it. Where a document cannot be read, that is recorded rather than estimated.

**This repository is empty.** Its contents are being prepared.
